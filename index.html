SCOM Monitoring Dashboard | Gulab Pathak

SCOM Monitoring Dashboard

Centralized Infrastructure Health & Performance Monitoring

Overview

The SCOM Monitoring Dashboard is a complete enterprise-grade monitoring solution built using System Center Operations Manager (SCOM). This project showcases my experience designing, implementing, and optimizing end-to-end monitoring for Windows servers, network devices, SQL databases, and business-critical applications.

Dashboard Provides Visibility Into:

  • Windows Server health & resource performance
  • Active Directory, DNS, DHCP services
  • SQL Server performance, services & DB availability
  • IIS & Web Applications
  • Network devices through SNMP (switches, routers, firewalls)
  • Capacity, resource utilization & trend analysis
  • SLA & uptime compliance

Architecture

Core Architecture Components

  • SCOM Management Server
  • Operations Database & Data Warehouse
  • SCOM Gateway Server for DMZ monitoring
  • Windows/Linux SCOM Agents
  • SCOM Web Console for dashboards
  • Custom & Vendor Management Packs
  • SNMP Network Discovery and Monitoring

The data collection pipeline uses event logs, SNMP, performance counters, health probes, and custom scripted checks to present a unified health model across the entire infrastructure.

Key Features

1. Real-Time Server Health Monitoring

Monitors CPU, Memory, Disk IOPS, network bandwidth, WinRM services, and system logs for proactive alerts.

2. Application & Service Monitoring

  • AD DS health (replication, FSMO role checks)
  • DNS/DHCP service availability
  • IIS Web App health including AppPool restarts
  • SQL Server agent, DB status, backup monitoring

3. Network Device Monitoring using SNMP

Integrated SNMP-based discovery for switches, routers, and firewalls. Network dependency monitors detect upstream outages and prevent cascading alerts.

4. Custom Management Packs

Developed tailored MPs for organization-specific applications, including discoveries, event rules, monitors, and PowerShell-based automated recovery tasks.

5. NOC-Style Dashboard

  • Global health state overview
  • Alert severity & category views
  • Performance & trend charts
  • SLA compliance heatmaps

Technical Workflow

Project Workflow Phases

  1. Requirements & KPI Gathering: Identify critical servers, SLAs, and thresholds.
  2. SCOM Infrastructure Validation: Optimize DB, DW, MS health, RunAs accounts.
  3. Management Packs: Import baseline MPs, create custom overrides, add application MPs.
  4. Dashboard Construction: Build state, alert, performance, SLA dashboards.
  5. Automation: Implement PowerShell auto-remediation actions.
  6. Reporting: Build SLA, health, and capacity planning reports.

  • SQL Server (SCOM DB & DW)
