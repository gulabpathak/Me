## 📄 About This Website
This website is a single-page, mobile-responsive HTML/CSS site — built without JavaScript — and optimized for recruiter viewing and GitHub Pages hosting.

**Sections include:**
- **About Me:** A brief overview of my experience and interests in Cloud and IT Infrastructure.
- **Skills:** A summary of core technologies and tools (Azure, AWS, GCP, VMware, WSUS, Terraform, etc.).
- **Projects:** A selection of practical and lab-based projects demonstrating my technical proficiency.
- **Contact:** Direct links for email, LinkedIn, and GitHub, plus a simple contact form.

**Extras:**
- "Download My Resume" button triggers an automatic download of my latest resume (`assets/Gulab_Pathak_Cloud_Resume.pdf`).
- Auto-deployment GitHub Actions workflow included (`.github/workflows/deploy.yml`).
- Ready for hosting at [https://gulabpathak.github.io/Me/](https://gulabpathak.github.io/Me/).

## ⚙️ Deployment Instructions
1. Clone this repository or download the ZIP.
2. Push the contents to a GitHub repository (e.g., `gulabpathak.github.io/Me`).
3. Enable **GitHub Pages** from the repository Settings → Pages → Source = `main branch`.
4. GitHub Actions (`deploy.yml`) will auto-publish the site on every push.
